# Emadawini IT Services 🛠️

A modern, responsive website for **Emadawini IT Services** — a tech solutions company based in Siyabuswa, Mpumalanga, offering hardware repairs, software services, and web development.


---

## 🚀 Features

- Animated hero section with floating icons
- Services showcase (Hardware Repair, Software Services, Web Development)
- Stats section (Devices Repaired, Happy Customers, Years of Experience)
- How It Works process steps
- Contact section with Phone, WhatsApp, Email, and Location
- Smooth scroll-to-top button
- Fully responsive on mobile and desktop

---

## 🧰 Tech Stack

- [React 18](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)
- [Motion (Framer Motion)](https://motion.dev/)
- [Lucide React Icons](https://lucide.dev/)

## 📦 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/Sbongiseni-hub/EmadawiniITService.git

# Navigate into the project
cd EmadawiniITService

# Install dependencies
npm install
```

### Running the Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
```
